# VK-бот: структура проекта

Раньше весь бот лежал в одном файле `kaz.py` (16 тысяч строк, из них 6 тысяч — картинки, записанные текстом).
Теперь код разложен по файлам, а картинки и шрифт лежат в папке `assets/` как обычные файлы.
**Логика бота не менялась**: старый и новый код проверены на одинаковых сценариях и отвечают одинаково.

## Запуск

    pip install vk_api pillow requests
    python kaz.py

(`python main.py` делает то же самое. Все файлы и папка `assets/` должны лежать рядом.)

Цены, награды, лимиты и тайминги меняются в **`config.py`** — там всё собрано в одном месте.

## Как обновить репозиторий на GitHub (без потери старой версии)

1. В репозитории ничего не удаляйте: картинки, `bot.db`, `.gitignore`, `requirements.txt` и README остаются как есть.
2. Откройте репозиторий → **Add file → Upload files**, распакуйте архив, выделите **все** файлы и папку `assets`, перетащите в окно GitHub.
3. Нажмите **Commit changes** (для подстраховки можно выбрать **Create a new branch**, а потом **Merge pull request**).
4. Запустите бота (`python kaz.py`) и проверьте профиль, бонус, рулетку.
5. В `requirements.txt` должны быть строки `vk_api`, `pillow` и `requests`.

## Команды бота (описание из старого файла)

```
VK-бот для бесед.

Для всех:       донат, укусить (Вампир), команды, профиль, префикс, топ, история, правила, бонус, кошелёк, передать,
                купить вип, бит (биткоин), бизнес, доход, рыбалка, мины, дуэль, рулетка, краш, крно (крестики-нолики), промокод, реф, репорт, админы,
                магазин, мои аксессуары, аукцион (аук), продать перс / бизнес
Мл Модератор:   хелп, удалить, профиль (чужой), варн
Ст Модератор:   мут, размут, снять варн
Администратор:  права, кик, бан, разбан, префикс (смена), timeout
Тех специалист: деньги (до 50кк сразу, больше — с разрешения владельца), опыт;
                промокод, забрать деньги, забрать опыт — с разрешения владельца
Владелец:       logs; права следящий (должность «Следящий за репортами»);
                в ЛС боту: разбан (репорты), следящие, промокод, деньги (себе), дрон вкл/выкл, вернуть (пропавшие деньги по репорту)
Следящий за репортами (не модератор беседы): новый вопрос приходит всем свободным следящим и владельцу
                с кнопками «Принять / Отказать»; кто принял — тот и отвечает, пока занят — новые не приходят;
                после разговора игрок оценивает следящего (5 кнопок-звёзд, 1–5)

Данные хранятся в базе SQLite (файл bot.db); старые JSON-файлы переносятся автоматически.

Установка:  pip install vk_api pillow
Запуск:     python kaz.py
```
